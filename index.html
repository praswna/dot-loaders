dot-loaders 점으로 만든 대기 애니메이션 연구실

각 카드는 한 변형(variant)입니다. 왼쪽은 선택한 크기, 오른쪽은 실제 UI 에 들어갈 20px 크기. ▶ 로 등장·반복, ■ 로 이음새에서 퇴장. 모든 변형은 가운데 한 점에서 퍼져 나오고 한 점으로 모이므로, 변형 사이를 끊김 없이 오갈 수 있습니다.

순환 재생

한 점 → 변형 → 한 점 → 다음 변형 … 모든 변형을 차례로 돕니다. 각 변형은 한 바퀴 이상, 3초 이상 돈 뒤 다음 이음새에서 한 점으로 모였다가 다음으로 퍼집니다.

mount(el, { variant: ['claude-code', 'ring', 'snake'], loops: 1, dwell: 3000 });
loader.next();          // 다음 변형으로 (한 점을 거쳐)
loader.next('dice');    // 특정 변형으로
